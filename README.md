# 多配置组报价配置 · 操作原型

REQ-20261029-001 · v1.3 · 2026-10-30

基于现有报价配置页面制作的静态交互原型。核心目标是把“买家配置、渠道配置、买家类型、价格标签”整合为可复用的配置组，并支持一条配置维护多个配置组。

## 本次调整

1. 移除“品牌配置”区域及“选择品牌”字段。
2. 新增“配置组”区域，每组统一维护：
   - 应用买家
   - 应用渠道
   - 买家类型
   - 价格标签
   - 价格区间、中标价差、费用规则
3. 配置组使用 Tab 栏切换维护，支持新增多个配置组，并可：
   - 新增空白配置组；
   - 复制上一组，新建 Tab 并完整继承买家、渠道、标签、价格与费用；
   - 复制任意一组并插入为该组后的新 Tab；
   - 删除配置组（至少保留一组）。
4. 价格规则完全移入当前配置组，切换 Tab 后独立读写，互不影响。
5. 价格与首条费用合并为同一行配置：最低价、最高价、中标价差与费用字段同排展示，不再拆成独立价格区与费用区。
6. 页面使用紧凑布局；中等桌面宽度自动收起右侧栏，保持价格与费用单行，移动端字段合理换行且无横向溢出。
7. 保留基础信息、状态、失效时间，并增加发布前完整度检查。

## 可操作流程

1. 填写配置名称、描述、优先级、状态和失效时间。
2. 新增配置组，通过弹窗选择买家，或批量导入 CSV。
3. 选择多个渠道和买家类型，录入价格标签。
4. 在配置组内同一配置行设置最低价、最高价、中标价差及首条费用；后续费用沿用同组价格。
5. 使用“复制上一组”复制最近一组的全部配置，或使用组内“复制本组”复制指定组；价格与费用会一并继承。
6. 点击“保存草稿”保存到浏览器本地演示空间。
7. 点击“发布配置”触发完整校验，通过后展示演示配置编号。

## 交互边界

- 全部买家、渠道、配置编号与金额均为脱敏演示数据。
- 页面为纯静态原型，不连接真实后端、数据库或生产服务。
- 草稿使用浏览器 `localStorage` 保存，仅用于原型演示。
- 买家导入支持 CSV/TXT 本地解析，不执行上传。
